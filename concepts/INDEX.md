## How to Add a Concept

When introducing a new domain concept:

1. Create a new file: `concept-name.md`
2. Use template:
   ```markdown
   # [Concept Name]
   
   ## Definition
   What is this?
   
   ## Why It Matters
   Why important for this project?
   
   ## Key Terms
   - Term: Definition
   
   ## Related
   - [Link to architecture doc]
   - [Link to other concept]
   
   ## Example
   Example from project
   ```
3. Add entry to this INDEX.md
4. Add entry to root [INDEX.md](../INDEX.md)
