# Hợp đồng API máy chủ license — đã chuyển

Từ [#381](https://github.com/natuan1/peekvn/issues/381) (2026-11-22), hợp đồng giữa app (Windows **và** macOS)
và máy chủ license nằm ở **một chỗ**: [`peekvn/services/license/README.md`](https://github.com/natuan1/peekvn/blob/main/services/license/README.md),
mục *Hợp đồng API*, cạnh mã của Cloudflare Worker và các ca hợp đồng dùng chung (`services/license/contract/`).

Trang này không còn nội dung để không có hai bản hợp đồng. Bản cũ (`SNPY-…`, 5 Slot, token `v = 1`,
`app=snappy-windows`, `license.snappy.vn`) xem trong lịch sử git của trang này.
